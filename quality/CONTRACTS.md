## lib/validation.ts
- C-01 `validateMyMapsUrl` returns true only for: https + host ∈ {www.google.com, google.com} + path startswith `/maps/d/` + non-empty `mid`. → REQ-002b
- C-02 `validateMyMapsUrl` never throws on malformed input (URL parse wrapped in try/catch). → REQ-002b
- C-03 `toMyMapsEmbedUrl` canonicalizes any valid variant to `https://www.google.com/maps/d/embed?mid=<mid>`. → REQ-002
- C-04 `toMyMapsEmbedUrl` throws on invalid input (calls validator first). → REQ-002
- C-05 *(intended, not yet met)* `mid` must be URL-encoded / structurally safe in the embed output. → REQ-002 (gap C2)
