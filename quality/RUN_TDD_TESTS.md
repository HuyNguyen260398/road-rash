# TDD Verification Protocol — road-rash

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-06-21 · Project: road-rash

Red-green verification for each confirmed bug. Framework: **Vitest** (matches the repo). Regression
tests live in `quality/test_regression.test.ts`; run with `pnpm test quality/test_regression.test.ts`.

## Per-bug cycle
For each `BUG-NNN` in `quality/BUGS.md` with a fix patch:
1. **Red:** with the fix NOT applied, run the bug's regression test. It MUST fail. Capture to
   `quality/results/BUG-NNN.red.log` (first line `RED`).
2. **Green:** `git apply quality/patches/BUG-NNN-fix.patch`, re-run. It MUST pass. Capture to
   `quality/results/BUG-NNN.green.log` (first line `GREEN`). Revert the patch after (source stays clean).
3. Record verdict in `quality/results/tdd-results.json` and the BUG tracker.

## Spec-grounded tests (write these in Phase 3)
- **BUG-001 (REQ-001, C1):** `getDisplayName({claims:{email:"x@y.com"}})` must NOT return `"x@y.com"`.
  Use Vitest `test.fails(...)` until the fix lands. Spec basis: REQ-001 / privacy intent.
- **BUG-002 (REQ-002, C2):** `validateMyMapsUrl(".../viewer?mid=a b")` must be `false`, and
  `toMyMapsEmbedUrl` over a `mid` with a reserved char must not emit it raw. Spec basis: REQ-002.
- **BUG-003 (REQ-003, C3):** `validateTripInput({...valid, thumbnailKey:"etc/x"})` must be
  `{ok:false}`. Spec basis: REQ-003.

The fix diffs for all three are pre-drafted in `quality/SUGGESTED_CHANGES.md` — convert each to a
`quality/patches/BUG-NNN-fix.patch`.

## Bug writeups
For each confirmed bug, generate `quality/writeups/BUG-NNN.md` with an inline ```diff``` fix block
(reuse the diffs from SUGGESTED_CHANGES.md), the spec reference (the REQ), the observable
consequence, and the FAIL→PASS evidence.
