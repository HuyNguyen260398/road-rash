## Audit prompt (copy-paste per auditor)

> You are auditing the road-rash codebase (Next.js + AWS Lambda/DynamoDB/Cognito/S3/Gemini) against
> `quality/REQUIREMENTS.md`. The central constraint: a trip's My Maps map is **user-supplied data**
> rendered in an iframe — there is no My Maps API. For each requirement, read the cited code and
> return SATISFIED / VIOLATED / UNCLEAR with a **file:line** and a one-line reason. Guardrails: line
> numbers mandatory; read bodies; grep before claiming missing; flag uncertainty as UNCLEAR. Do not
> propose style changes. A code-path trace that shows a behavioral violation is sufficient to confirm
> — you do NOT need runtime evidence.

## Pre-audit docs validation

No citable formal spec ships (`reference_docs/` absent); `docs/architecture.md`,
`docs/road-rash-plan.md`, and `docs/Project_Architecture_Blueprint.md` are the intent baseline.
All requirements are Tier 3 (code-is-spec). Auditors should treat the `docs/` risk/assumption tags
(RISK-005, ASSUMPTION-001, SEC-003, CON-001) as authoritative design intent.

## Secondary emphasis lenses
- Auditor 1 — **privacy / public read surface** (REQ-001, REQ-009): trace every field that reaches
  a public route and the public share page.
- Auditor 2 — **URL/iframe handling** (REQ-002, REQ-002b): hostile `mid`, host allow-list bypass,
  CSP `frame-src`/`sandbox` interplay.
- Auditor 3 — **authz & input** (REQ-003, REQ-004, REQ-005): ownership branches, thumbnailKey scope,
  validator completeness.

Each auditor still performs a full pass; the lens only biases attention.

## Triage
Merge findings. Any **minority finding** (1 of 3) gets a re-investigation with a verification probe
(read the exact lines; write an executable assertion). Apply the **scaffolding exclusion** (ignore
self-documenting placeholders) and the **challenge gate** for security-class findings before
confirming. Expected high-confidence confirmations: C1 (REQ-001), C2 (REQ-002). C3 likely
confirmed; C4/C5 should be classified as documented design boundaries, not defects.

Write per-auditor reports to `quality/spec_audits/2026-06-21-auditor-{1,2,3}.md` and the synthesis
to `quality/spec_audits/2026-06-21-triage.md`. Sync confirmed code bugs into `quality/BUGS.md`.
