# Integration Test Protocol — road-rash

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-06-21 · Project: road-rash

**Working directory:** project root; all commands use relative paths. These exercise the deployed
**staging** stack (real Cognito/API Gateway/DynamoDB/S3/Gemini). Never run against prod; never
`terraform apply` prod locally.

## Safety / pre-flight
- Confirm `NEXT_PUBLIC_API_BASE_URL` points at **staging**.
- Have one staging test Cognito user (Google OAuth) and its ID token available.
- `pnpm build:lambdas` then `pnpm build` must pass before any deploy-dependent test.

## Test matrix

| Group | UC | What it verifies | Pass criteria |
|---|----|------------------|---------------|
| 1 | UC-01 | Public `GET /trips` + `GET /trips/{id}` render the shared trip; **no `authorName` is an email** | 200; `authorName` does not match an email regex |
| 2 | UC-03 | Paste each My Maps variant (view/edit/u-0); iframe loads or degrades to the validated link | embed renders, or the "Open map" fallback appears within 8s |
| 3 | UC-02 | Owner can `PUT`/`DELETE` own trip; a second user gets 403; anon gets 401 | 200/204 owner, 403 non-owner, 401 anon |
| 4 | UC-05 | `POST /uploads/presign` → PUT to S3 → trip references `thumbnails/<sub>/…`; public GET signs it | upload succeeds; key under caller's prefix; thumbnail renders |
| 5 | UC-04 | `POST /suggest` returns only real candidate-set ids; ghost id is dropped | every returned id ∈ candidates ∧ exists in DynamoDB |
| 6 | UC-04 | `/suggest` under burst is throttled | sustained burst > 5 yields 429 (per-route throttle) |
| 7 | [Infrastructure] | `pnpm build:lambdas && pnpm build && pnpm lint && pnpm format:check && pnpm test` | all green (the PR CI gate) |

## Structured output
Emit `quality/results/integration-results.json` (grouped schema with `uc_coverage` for UC-01..05)
and a Markdown summary. Recommendation ∈ SHIP / FIX BEFORE MERGE / BLOCK. Group 1 (email exposure)
and Group 3 (ownership) are **blocking** groups.

## Execution UX
(1) Print the matrix as a numbered table before running. (2) One-line `✓/✗/⧗` per group.
(3) Summary table + recommendation.
