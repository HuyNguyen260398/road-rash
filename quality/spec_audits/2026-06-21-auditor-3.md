# Spec Audit — Auditor 3 (lens: authorization & input validation)

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-06-21 · Project: road-rash · Audited against the patched tree

## Scope
REQ-003 (thumbnailKey namespace), REQ-004 (ownership), REQ-005 (write validation), plus the
favorites client/state path.

## Findings

- **REQ-003 — SATISFIED (fix verified).** `services/trips/validate.ts:97-99` now rejects any
  non-empty `thumbnailKey` not starting with `thumbnails/`. Confirmed the check runs on **both**
  write paths: `createTrip` and `updateTrip` both call `validateTripInput` (`trips/handler.ts:185,217`).
  Empty/absent keys still pass (the field is optional). Matches the upload-side scoping intent.
  - **Stronger option (not required):** thread the caller's `sub` and require `thumbnails/<sub>/` to
    block cross-user references entirely. Recorded in BUGS.md; current fix closes the stated REQ.

- **REQ-004 — SATISFIED.** `updateTrip`/`deleteTrip` (`trips/handler.ts:215,242`) compare
  `current.authorId !== sub` → 403; missing sub → 401. Favorites are keyed by the verified `sub`
  (`favorites/handler.ts:71,107`) so cross-user read/write is structurally impossible. Two-layer
  authz (gateway JWT + Lambda owner check) intact.

- **REQ-005 — SATISFIED.** Enum/duration/length/URL checks unchanged and covered by 23 functional
  tests; the validated output remains a whitelisted `TripInput` (no server-owned fields).

- **Favorites client (`FavoritesProvider.tsx`)** — reviewed for state-correctness bugs: the `inFlight`
  ref guards double-taps; optimistic flip + revert-on-error is symmetric; `signedOut` resets both
  sets. The `toggle` callback closes over fresh `favorited` (in deps). No defect.

- **Client search (`lib/search.ts`)** — `matchesQuery` is case-insensitive over the loaded set,
  confirming the **C4** boundary (server `contains` is case-sensitive + truncates at 200 before this
  refinement). Documented design boundary; not a bug at launch scale.

## Net-new findings
None.

## Verdict
REQ-003 fix confirmed effective; REQ-004/005 satisfied. No net-new bugs.
