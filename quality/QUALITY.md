# Quality Constitution — road-rash

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-06-21 · Project: road-rash

## 1. Purpose

Quality for road-rash means: **the public surface never leaks private data, user-supplied URLs can
never become an attack vector, and ownership is enforced server-side regardless of the client.**
Fitness-for-use here is not "tests pass" — it is "an anonymous visitor can browse and an
authenticated creator can manage *only their own* content, with no PII exposure and no way to make
the app render something it shouldn't." Quality is built in (validators, the host allow-list, the
two-layer authz), not inspected after the fact.

## 2. Coverage Targets

| Subsystem | Target | Why |
|---|---|---|
| `lib/validation.ts` (My Maps guard) | 100% | The security spine. This string becomes an iframe src; every branch must be tested. |
| `services/*/validate.ts` | 100% | Server is the authority; a missed branch is an oversized/spoofed write reaching DynamoDB. |
| `services/shared/auth.ts` | 100% | `getDisplayName` controls what PII reaches the public page (REQ-001). |
| `services/suggest-trips/select.ts` | 95% | Candidate containment + tolerant parsing protect cost + correctness. |
| `services/favorites/count.ts` | 100% | Tiny, pure, and the only guard against a negative public counter. |
| Lambda handlers | ≥70% | Routing + ownership branches; currently **0%** — the biggest gap. |

## 3. Coverage Theater Prevention

Project-specific fake-test patterns to reject in review:
- Asserting `validateMyMapsUrl(x)` returns *a boolean* instead of the correct boolean for a hostile `x`.
- Testing `toMyMapsEmbedUrl` only on clean ids — the point is the `&`/`#`/space `mid` (C2).
- Mocking the DynamoDB client to return a trip and asserting the mock was called, without checking
  the ownership 403/401 branch in `updateTrip`/`deleteTrip`.
- Testing `getDisplayName` only with a `name` claim present — the bug (C1) is the no-`name` path.

## 4. Fitness-to-Purpose Scenarios

1. **Email leaks to the public web.** Because `getDisplayName` ranks `email` above `cognito:username`,
   a creator whose Google token omits `name` has their email stored as `authorName` and rendered on
   the public `/trip/[id]` page (`TripDetail.tsx:182`). Detection is hard — no test exercises the
   no-`name` path, and it looks fine for any account that *does* have a name. **Verify:** REQ-001 tests.
2. **Corrupted/hostile `mid` reaches the embed src.** `toMyMapsEmbedUrl` interpolates an unencoded
   `mid`; a `#` truncates the query and a `&` injects a param into Google's embed endpoint. Today
   React-escaping + host-lock + CSP contain the blast radius, so the *visible* symptom is a broken
   map — but the unencoded interpolation is one copy-paste away from a real injection. **Verify:** REQ-002 tests.
3. **Cross-user thumbnail reference.** `thumbnailKey` isn't namespace-checked on write, so a bypassed
   client can point a trip at any `thumbnails/*` object. Low impact today; an authz inconsistency.
   **Verify:** REQ-003 tests.
4. **Counter goes negative / drifts.** The two-write favorite path can drift the denormalized counter
   under a crash or concurrent toggle; the floor guard stops *negative* values but not drift.
   **Verify:** REQ-008 tests + confirm `scripts/reconcile-favorites.ts` is runnable.
5. **Silent search truncation.** Case-sensitive server `contains` + a 200 `slice` before client
   refinement can drop case-variant matches at scale. Correct-looking but incomplete. **Verify:**
   document the boundary; add a requirement test if/when normalized search lands.
6. **AI cost runaway.** `/suggest` is public. Mitigated by per-route throttling (burst 5/rate 2) and
   candidate bounds — verify the throttle stays in the prod tfvars on every infra change. **Verify:**
   integration check that the route 429s under burst.

## 5. AI Session Quality Discipline

- The server validators are the authority — never weaken them "because the client already checks."
- Any change touching `getDisplayName`, `validateMyMapsUrl`, or `toMyMapsEmbedUrl` requires a test.
- One focused commit per change (repo convention); run `pnpm format:check && pnpm lint && pnpm test`
  before pushing (the PR CI gate runs all three).
- Never `terraform apply` prod locally (destroys the Google/GitHub IdP wiring — see project memory).

## 6. The Human Gate

- Whether to scrub existing `authorName` values that already contain emails (data migration).
- Whether to tighten the `mid` charset (could reject a legitimate legacy id) vs. encode-only.
- Whether the public `authorId`/`sub` exposure is acceptable for the product.
